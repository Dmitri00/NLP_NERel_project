# Issue tracker: Local Markdown

Задачи и спецификации хранятся в `.scratch/`.

## Структура

- Одна функциональность — `.scratch/<feature-slug>/`.
- Спецификация — `spec.md` внутри этой папки.
- Каждая задача — отдельный файл `issues/<NN>-<slug>.md`,
  нумерация начинается с `01`.
- Статус triage — строка `Status:` в начале задачи.
  Значения описаны в `triage-labels.md`.
- Обсуждение добавляется в конец задачи под `## Comments`.

## Операции

«Опубликовать в трекере» означает создать соответствующий
Markdown-файл в `.scratch/<feature-slug>/`.

«Получить задачу» означает прочитать файл по указанному пути.
Если номер неоднозначен, уточнить функциональность.

## Wayfinder

- Карта исследования — `.scratch/<effort>/map.md` с разделами
  Notes, Decisions-so-far и Fog.
- Дочерние задачи — `issues/NN-<slug>.md`.
- `Type:` — research, prototype, grilling или task.
- Для этих задач `Status:` — open, claimed или resolved.
- Зависимости — `Blocked by: NN, NN`.
  Задача разблокирована, когда все зависимости resolved.
- Следующая задача — первая по номеру со статусом open
  и без незавершённых зависимостей.
- Перед работой установить claimed и сохранить файл.
- После работы добавить ответ под `## Answer`, установить
  resolved и внести вывод со ссылкой в Decisions-so-far карты.
