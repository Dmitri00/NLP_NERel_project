# NER и классификация характеристик новостей

Учебный проект по извлечению именованных сущностей и определению характеристик новостных текстов NEREL.

## Language

**Документ**:
Один текст из датасета, для которого определяются сущности и характеристики.

**Именованная сущность**:
Упоминание в тексте с заданным типом, например персона, организация или дата.

**Характеристика документа**:
Одна из 30 заданных в условии характеристик, применимость которой определяется для документа целиком. У документа может быть несколько характеристик одновременно.
_Avoid_: Единственный класс документа

**NER**:
Задача распознавания именованных сущностей в тексте и их типов.

**CLS**:
Задача определения применимости каждой из 30 характеристик документа.
_Avoid_: Взаимоисключающая классификация

**субтокенизации** - представление слова языка на токены-части слова

**разбивка** - диаграмма относительных частот значений переменной в датасете, сумма относительных частот = 100%
