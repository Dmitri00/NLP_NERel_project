# Triage labels

| Роль | Значение Status | Смысл |
| --- | --- | --- |
| needs-triage | needs-triage | Требует первичного разбора |
| needs-info | needs-info | Нужны дополнительные сведения |
| ready-for-agent | ready-for-agent | Готова для выполнения агентом |
| ready-for-human | ready-for-human | Требует выполнения человеком |
| wontfix | wontfix | Решено не выполнять |

При назначении роли используй соответствующее значение Status
в файле задачи.
