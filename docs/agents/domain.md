# Domain docs

Проект использует single-context:
- `GLOSSARY.md` в корне — термины проекта.
- `docs/adr/` — записи об архитектурных решениях.

## Перед изучением кодовой базы

Прочитай GLOSSARY.md и ADR, относящиеся к области работы.
Если документов ещё нет, продолжай без уведомлений
и предложений создать их заранее. Навык domain-modeling
создаёт их по мере появления согласованных терминов и решений.

## Терминология

Используй определения и названия из GLOSSARY.md в задачах,
предложениях, гипотезах и тестах.

Если нужного понятия нет, проверь, подходит ли существующий
термин. Реальный пробел отметь для domain-modeling.

## Архитектурные решения

Если предложение противоречит существующему ADR,
явно укажи документ, противоречие и причину пересмотра.
